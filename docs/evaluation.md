# Evaluation and independent audit

`avtriage.audit` draws without replacement within every nonempty stratum, including zero-proposal frames, with inclusion probability n/N. The default API/CLI design assigns every release image to zero, low (<0.5), or high (>=0.5) proposal-score bands; alternate predeclared strata may be supplied to the API and must cover the release exactly. When the budget cannot cover the default bands, adjacent bands are deterministically merged before drawing. Budgets smaller than the number of nonempty strata are rejected, so merge bands before freezing a design. Every review is a fresh full-frame decision and the blind endpoint returns original boxes and image IDs, not proposals, rankings, scores or queue decisions. Use the release media endpoint to view the full image. Decision events are append-only, with explicit supersession; independent disagreement remains unresolved until adjudicated. Scripted fixtures are not human reviews. No pilot agreement or reviewer timing has been measured.

The estimate is the population-weighted mean of stratum sample fractions. Two-sided finite-population hypergeometric inversion with Bonferroni correction yields simultaneous conservative 95% bounds. A census returns its exact count. Unknown or disputed samples suppress the point estimate and give all-unknown-negative and all-unknown-positive sensitivity results. A zero-finding sample usually has a nonzero upper bound. The target is this fixed population, not future drives; no optional stopping.

Run `PYTHONPATH=. python tools/audit_simulation.py` and `python -m unittest discover -s tests -p 'test_audit*'`. All possible success counts were enumerated for each N <= 8, all sample sizes and all population counts, with exact combinatorial weights; every one-stratum coverage was >= 95%. Six synthetic scenarios use seeds 0..999, populations 100/40/30, sample size 40 except 165 for near census. On 2026-11-19 all six had 1000/1000 intervals covering the finite-population truth; Wilson 95% Monte Carlo interval for each observed coverage was [0.9962, 1.0000]. Median interval widths ranged from 0.0176 near census to 0.5118 in the half-positive clustered-label scenario. Mean bias ranged from 0 to 0.00184 in magnitude. These simulations model fixed truth and random samples, not visual inspection, reviewer behavior, or independence of neighboring frames. The duplicate-looking scenario models correlated truth labels, not image similarity measurements.

`avtriage.benchmark.score` is separate from mining and accepts a frozen queue and private known-omission boxes, with image-level budgets 25/50/100, one item per image, IoU >= 0.5, ties by reference ID, and each reference box credited once. It reports known recovery per reviewed image; unmatched items are unknown, so this is not human-verified precision. `tools/benchmark_reference.py` builds those boxes privately from KITTI and ReChecked and scores an already-frozen JSON queue. Do not use correction data to select the evaluation images, fit models, index candidates or rank. Comparisons, group-resampled confidence intervals, real human precision, detector ceiling and timing are outstanding until actual outputs and independent groups have been evaluated.

The frozen held-out scorecard is `artifacts/reference/kitti-scorecard.json`: 133 evaluation images, 44 source drives, one development seed, two known omitted boxes. Raw and policy-eligible proposal ceilings each reach one of two known boxes. At image budgets 25/50/100, random full-frame review reaches 0/0/1 images with known omissions; confidence reaches 2/2/2, similarity 1/2/2 and fusion 2/2/2. None of the suggested boxes match a known omission in the first 100. Image reach assumes a reviewer inspects the entire frame. With one seed and two known boxes this is exploratory and does not establish a gain; no review times or human confirmations exist. All queues were fixed and hashed before private scoring; model output is private local data. The independently computed tile-only run reaches 0/1/1 known images and fusion with tile hints reaches 2/2/2 at 25/50/100; hint crops are not credited as matched boxes. The tile run processed 2,527 crops in 45.56 seconds excluding model startup, with about 21 MiB cache and 512,999,424-byte peak RSS. Conditional paired drive-bootstrap intervals (2,000 replicates, seed 20261119, 44 drives) appear in the artifact; with two known boxes and one seed, they do not establish generalization.
